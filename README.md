WhiteVPN

Modern personal VPN application for Windows and Android.

Features

- Modern interface
- WireGuard VPN protocol
- Server selection
- Connection status
- IP address display
- Light and dark themes

Platforms

- Windows 10 / 11
- Android

Technologies

- Java 21
- JavaFX
- Kotlin
- WireGuard
